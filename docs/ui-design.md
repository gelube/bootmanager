# Boot Manager Pro - UI 设计规范

## 概述
本文档定义 Boot Manager Pro 的 UI 设计规范，确保界面风格统一、专业美观。

---

## 1. 整体布局

### 窗口尺寸
- **主窗口**: 900 × 600 像素
- **最小尺寸**: 800 × 500 像素（保证内容可读性）

### 布局结构
```
┌─────────────────────────────────────────────────────────┐
│  Boot Manager Pro                    [最小化] [关闭]   │
├──────────┬──────────────────────────────────────────────┤
│          │                                              │
│  导航栏   │              内容区域                        │
│  200px   │              (自适应宽度)                     │
│          │                                              │
│          │                                              │
│          │                                              │
│          │                                              │
│          │                                              │
├──────────┴──────────────────────────────────────────────┤
│  状态栏                                                  │
└─────────────────────────────────────────────────────────┘
```

### 区域说明
| 区域 | 宽度 | 说明 |
|------|------|------|
| 左侧导航栏 | 200px | 固定宽度，垂直排列功能按钮 |
| 右侧内容区 | 自适应 | 根据窗口大小自动调整 |
| 底部状态栏 | 100% | 显示操作状态和提示信息 |

## 2. 颜色规范

### 主色调
| 用途 | RGB 值 | 十六进制 | 说明 |
|------|--------|----------|------|
| 背景色 | RGB(18, 18, 22) | `#121216` | 深色背景，主窗口底色 |
| 卡片色 | RGB(28, 28, 34) | `#1C1C22` | 卡片/面板背景色 |
| 主色调 | RGB(59, 130, 246) | `#3B82F6` | 科技蓝，用于按钮、高亮 |
| 悬停色 | RGB(96, 165, 250) | `#60A5FA` | 悬停状态高亮 |
| 按下色 | RGB(37, 99, 235) | `#2563EB` | 按钮按下状态 |
| 文字色 | RGB(243, 244, 246) | `#F3F4F6` | 主文字颜色 |
| 次要文字 | RGB(156, 163, 175) | `#9CA3AF` | 说明文字、标签 |
| 边框色 | RGB(55, 65, 81) | `#374151` | 分割线、边框 |
| 成功色 | RGB(34, 197, 94) | `#22C55E` | 成功状态指示 |
| 警告色 | RGB(234, 179, 8) | `#EAB308` | 警告状态指示 |
| 错误色 | RGB(239, 68, 68) | `#EF4444` | 错误状态指示 |

### 颜色使用原则
- 背景使用深色系，减少视觉疲劳
- 主色调用于交互元素（按钮、选中状态）
- 文字层次分明：主文字 > 次要文字 > 禁用文字
- 状态色仅用于特定状态指示，不用于装饰

## 3. 按钮规范

### 按钮类型

#### 主按钮（Primary Button）
- **样式**: 填充背景色
- **背景**: RGB(59, 130, 246)
- **文字**: RGB(243, 244, 246)
- **圆角**: 6px
- **用途**: 主要操作、确认动作

#### 次按钮（Secondary Button）
- **样式**: 边框样式
- **边框**: 1px solid RGB(55, 65, 81)
- **背景**: 透明
- **文字**: RGB(243, 244, 246)
- **圆角**: 6px
- **用途**: 次要操作、取消动作

#### 危险按钮（Danger Button）
- **样式**: 填充背景色
- **背景**: RGB(239, 68, 68)
- **文字**: RGB(243, 244, 246)
- **圆角**: 6px
- **用途**: 删除、卸载等危险操作

### 按钮尺寸
| 类型 | 宽度 | 高度 | 字体大小 | 用途 |
|------|------|------|----------|------|
| 标准按钮 | 120px | 35px | 13px | 常规操作 |
| 大按钮 | 150px | 40px | 14px | 重要操作 |
| 小按钮 | 90px | 30px | 12px | 辅助操作 |

### 按钮状态
| 状态 | 效果 |
|------|------|
| 正常 | 标准样式 |
| 悬停 | 背景色变为 RGB(96, 165, 250)，轻微放大 |
| 按下 | 背景色变为 RGB(37, 99, 235) |
| 禁用 | 透明度 50%，无交互效果 |

### 字体规范
- **字体**: Microsoft YaHei UI
- **字重**: Regular (400)
- **标准按钮**: 13px
- **大按钮**: 14px
- **小按钮**: 12px

## 10. 设计原则

### 视觉层次
1. **标题** > 正文 > 辅助文字
2. **主按钮** > 次按钮 > 文字按钮
3. **选中状态** > 悬停状态 > 正常状态

### 一致性
- 所有圆角统一使用 6px（按钮）或 8px（卡片）
- 间距使用 4px 的倍数
- 颜色严格遵循色板定义

### 可访问性
- 文字与背景对比度 ≥ 4.5:1
- 交互元素最小尺寸 44×44px
- 状态变化有视觉反馈

### 深色主题适配
- 避免纯黑纯白，使用柔和的深色/浅色
- 阴影效果减弱或移除（深色背景上不明显）
- 使用边框分隔代替阴影
